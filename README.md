# Terraform AWS EC2 Project

## What This Does

Automates the provisioning of AWS infrastructure using Terraform. The project creates and manages EC2 instances through Infrastructure as Code (IaC), enabling consistent and repeatable deployments.

## Tech Stack

Terraform • AWS EC2 • AWS VPC • GitHub • Linux

## How It Works

1. Terraform configuration files define the AWS infrastructure.
2. Variables are used to customize resource creation.
3. Terraform provisions the EC2 instance and related resources.
4. Outputs provide useful deployment information such as instance details.

## Files

* `main.tf` – Defines AWS resources and infrastructure.
* `variables.tf` – Stores input variables for customization.
* `outputs.tf` – Displays resource outputs after deployment.

## Key Concepts Demonstrated

* Infrastructure as Code (IaC)
* Automated AWS resource provisioning
* Reusable Terraform configurations
* Version-controlled infrastructure using GitHub
* Infrastructure lifecycle management with Terraform
